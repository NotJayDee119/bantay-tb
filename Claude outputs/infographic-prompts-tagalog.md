# Infographic prompts — 6 diseases × 5 sections (30 images)

Each prompt stands alone, so you can paste it into a new chat in any image tool
(ChatGPT, Gemini, Ideogram, etc.). The text is plain everyday Tagalog, with
English for words Filipinos already use (inhaler, vaccine, test, mask).

Every fact comes from the app's own article text (`src/data/healthContent.ts`).

**File names** follow the app's slots: `covid-overview`, `covid-symptoms`, `covid-treatment`,
`covid-prevention`, `covid-lifestyle`, and the same pattern for `influenza`, `bronchitis`, `copd`,
`asthma` and `paragonimiasis`. Size: portrait **3:4** (896 × 1200), like the current pictures.

## Checking the image before you use it
Image tools often misspell words. Before saving a picture:
1. Check every word against the quoted text in its prompt, letter by letter.
2. If even one word is wrong, regenerate it, or cover that word in Canva and type it again.
3. Don't fix wrong text by guessing: the quoted text in the prompt is the correct version.
